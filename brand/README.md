# Project branding

These SVG files provide the repository and documentation branding for Analog Gauge Card.

Analog Gauge Card is a Home Assistant **Dashboard plugin / custom Lovelace card**, not a `custom_components` integration. The Home Assistant integration brands mechanism therefore does not automatically use these files.

Files:

- `icon.svg` — square project icon
- `logo.svg` — logo for light backgrounds
- `dark_logo.svg` — logo for dark backgrounds
