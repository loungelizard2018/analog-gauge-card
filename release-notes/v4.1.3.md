## Analog Gauge Card v4.1.3

This is a branding and documentation release. The gauge rendering and YAML behaviour remain unchanged from v4.1.2.

### Added

- Dedicated vector project icon
- Light and dark vector project logos
- Clear documentation explaining that Analog Gauge Card is a Dashboard plugin rather than a `custom_components` integration

### Card type

```yaml
type: custom:analog-gauge-card
```

The previous `custom:analog-gauge-card-v412` name remains available as a compatibility alias.
